# lubridate
lubridate 是 tidyverse 生态中专门用于简化日期和时间处理的 R 包。

## 核心优势:
  - 降低日期、时间转换的复杂度，无需记忆繁琐的 format 格式符（如 %Y/%m）
  - 提供直观、语义化的函数名，新手易记易用
  - 支持日期时间的加减、提取、时区转换等操作

## 核心功能：

### 1. 日期/时间转换

把混乱排序的日期时间按「年/月/日」顺序命名，自动识别多种分隔符（ - /空格/ . / 无分隔符），无需手动指定 format。

|函数|含义|示例代码|输出结果|
|-|-|-|-|
|`ymd()`|年-月-日|`ymd("2026/01/20")`|2026-01-20|
|`mdy()`|月-日-年|`mdy("01/20/2026")`|2026-01-20|
|`dmy()`|日-月-年|`dmy("20.01.2026")`|2026-01-20|
|`ymd_hms()`|年-月-日 时:分:秒|`ymd_hms("20260120 14:30:45")`|2026-01-20 14:30:45|
|`ymd_hm()`|年-月-日 时:分|`ymd_hm("2026-01-20 14:30")`|2026-01-20 14:30:00|

### 2. 提取日期/时间组件

根据给定的日期/时间对象提取指定维度的信息

**示例日期时间:**`dt <- ymd_hms("2026-01-20 14:30:45")`

  - **提取核心组件**
    |示例代码|含义|输出结果|
    |-|-|-|
    |`year(dt)`|提取年|2026|
    |`month(dt)`|提取月|1|
    |`day(dt)`|提取日|20|
    |`hour(dt)`|提取小时|14|
    |`minute(dt)`|提取分钟|30|
    |`second(dt)`|提取秒|45|

  - **提取星期**
    |示例代码|含义|输出结果|
    |-|-|-|
    |`wday(dt)`|数字型星期（1=周日，7=周六）|3|
    |`wday(dt, label = TRUE)`|星期标签|Tue|
    |`month(dt, label = TRUE)`|月份标签|Jan|

### 3. 日期/时间运算
支持直观的时间加减，搭配 days()/months()/years() 等函数使用。

  - **时间加减**

    **示例日期:**`dt <- ymd("2026-01-20")`

    |示例代码|含义|输出结果|
    |-|-|-|
    |`dt + days(5)`|加5天|2026-01-25|
    |`dt - months(2)`|减2个月|2025-11-20|
    |`dt + years(1)`|加1年|2027-01-20|
    |`dt + hours(3) + minutes(15)`|加3小时15分钟|2026-01-20 03:15:00|

  - **计算时间差**

    **示例日期:**
    `start <- ymd("2026-01-01")`
    `end <- ymd("2026-01-20")`

    |示例代码|含义|输出结果|
    |-|-|-|
    |`as.duration(end - start)`|时长差|19d 0H 0M 0S|
    |`difftime(end, start, units = "days")`|天数差|19 days|

### 4. 实用工具函数

  - **获取当前时间:**
    |示例代码|含义|输出结果|
    |-|-|-|
    |`today()`|当前日期（无时间）|2026-01-20|
    |`now()`|当前日期+时间|2026-01-20 14:30:45|

  - **时区操作:**

    **示例日期:**`dt <- now()`

    |示例代码|含义|输出结果|
    |-|-|-|
    |`tz(dt)`|查看对应时区|"Asia/Shanghai"|
    |`with_tz(dt, "America/New_York")`|"2026-01-20 09:30:45 EST"|

    **注**：当时间对象的时区属性为 NULL（即未显式指定时区）时，tz() 函数会返回空字符串 ""，以此表示该时间采用的是操作系统的默认本地时区。

## as.Date() vs ymd()
  - as.Date() 是 R 基础包（base R）自带的函数
  - ymd() 是 lubridate 包（tidyverse 生态）提供的函数

### 1.自动识别能力

  - **as.Date()**:对日期格式的容错性极低，默认只识别 YYYY-MM-DD（如 2026-01-19）这种标准格式。如果日期是其他格式（比如 2026/01/19、26-01-19、2026年01月19日 或 01/19/2026），直接用 as.Date() 会返回 NA（缺失值），必须手动指定 format 参数：

    |示例代码|含义|输出结果|
    |-|-|-|
    |`df$date <- as.Date("2026/01/19")`|错误示例：非标准格式直接转换会失败|返回 NA|
    |`df$date <- as.Date("2026/01/19", format = "%Y/%m/%d")`|正确示例：必须指定格式|成功转换为 2026-01-19|
